# Hi, I'm Juan José 👋

Systems Engineering student at **Universidad EAFIT** (Medellín, Colombia), focused on the intersection of **business processes, data and technology**. I like understanding how an organization works before deciding what system it needs.

In university projects I've diagnosed a real construction company's technology and built the information system the team recommended, co-written ISO/IEC/IEEE 29148 requirements specifications in Scrum teams, and built a multi-LLM system that evaluates cost, latency and quality across providers. I also enjoy going low level: I've extended the xv6 kernel with syscalls and page-table mechanisms.

## Featured projects

| Project | What it is | Stack |
|---|---|---|
| [SGI-CIRNSAS](https://github.com/jjacevedo/cirnsas-mvp) | Information system for a construction company: apartment inventory, sales, payments and budget vs. actual control | React, Express, MySQL, Docker, GitHub Actions |
| [JJAPIS](https://github.com/jjacevedo/jjapis) | Queries several LLM providers in parallel and synthesizes one answer, with cost, latency and quality evaluation | FastAPI, Next.js, PostgreSQL, Docker |
| [RutasMDE](https://github.com/jjacevedo/RutasMDE) | Mobility copilot for Medellín with A* routing, an LLM agent and RAG | Python, Streamlit |
| [PriceWise](https://github.com/Are0206/PriceWise) | Supermarket price comparison built by a four-person Scrum team | Django, AWS |
| [TuneHold](https://github.com/jjacevedo/TuneHold) | Music player for the files you own (in development) | TypeScript, Next.js, Turborepo |
| [xv6 page tables](https://github.com/jjacevedo/proyecto-3-sistemas-operativos) | USYSCALL page, `vmprint()` and `pgaccess()` in xv6-riscv | C |
